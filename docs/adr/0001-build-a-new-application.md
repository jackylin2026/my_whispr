# Build a new application instead of forking OpenWhispr

My Whispr will be a new, independently branded application that uses OpenWhispr as a behavioral and technical reference rather than as its source-code base. This gives up the speed of deleting features from a working fork in exchange for a deliberately small architecture shaped only around personal dictation; isolated OpenWhispr code may still be reused when it provides clear value, provided its MIT attribution and any applicable third-party licenses are retained.
